# STYLE BIBLE — Tambahan v4 (motor, item, terrain, efek, game center)

> Melengkapi STYLE-BIBLE.md dan STYLE-BIBLE-INTERIOR.md. STYLE BLOCK dan NEGATIVE BLOCK yang sama tetap dipakai.

## 1. Motor dan pengendara
Motor matic sederhana tanpa merek: bodi navy `#34456B`, jok dan trim krem `#F7EEDA`, roda abu gelap, lampu depan bulat kecil, spion sederhana. Panjang ±80 px, tinggi ±64 px (selaras karakter 64 px). Pengendara memakai kanon karakter (rambut cokelat gelap, kaos krem, celana navy, sepatu cokelat, tas hijau gelap terlihat). Semua tampak memakai motor yang **sama persis** (warna, bentuk, proporsi).

## 2. Ikon item dan ikon HUD
32×32, warna datar dari palet, outline 1 px gelap, siluet sederhana, **kemasan tanpa teks/merek** (label kosong). Ikon makanan harus terbaca pada ukuran slot hotbar (skala bilangan bulat).

## 3. Terrain
Tanah datar bergaya "chunky pixel", hangat: aspal navy-abu lembut dengan marka krem, trotoar paving krem-cokelat muda, rumput muted green dengan rumput liar dan bunga kecil (krem/mustard/terracotta secukupnya), halaman tanah cokelat muda, bayangan kontak lembut satu nada di bawah pad bangunan. Tidak ada objek tinggi di plate.

## 4. Game center (eksterior)
Fasad navy dan krem, kanopi hijau muted bergaris, papan nama kosong (tanpa teks/neon/glow), jendela besar memperlihatkan siluet mesin arcade dengan layar warna datar, pintu kaca ganda di tengah bawah, dua meja bulat kecil di depan. Skala, outline, dan nuansa sama dengan sekolah/minimarket; dasar sprite rata di baris terbawah.

## 5. Efek visual prosedural
Hanya warna token: mustard `#D9A441` (kilau/bintang), krem `#E9D8B4`/`#F7EEDA` (cincin/debu), cokelat muda `#C9A27A` (debu), navy `#1F2A44` (outline teks efek). Bentuk persegi piksel, tanpa blur/glow halus.

## 6. Hotbar
Mengikuti `docs/reference/hotbar-reference.png` (slot krem berbingkai, tepi hangat) dan gaya UI buatan pengguna; ikon item menempel pas di slot; lencana jumlah kecil kanan-bawah.
