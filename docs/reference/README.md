# docs/reference — gambar acuan untuk agen

Simpan tangkapan layar Anda di sini dengan nama persis berikut sebelum menjalankan prompt:
- `bug-interior-berantakan.png` — ruang tamu dan dapur: furnitur dapur melayang/tersebar, tidak menempel dinding (acuan perbaikan tata letak).
- `hub-saat-ini.png` — tampilan peta kota saat ini (acuan terrain, bangunan game center di kanan-bawah, dan lokasi bug NPC ibu yang tertimpa rumah).
- `hotbar-reference.png` — contoh bar item kecil bawah-tengah (gaya yang diinginkan).
Agen wajib melihat gambar-gambar ini sebelum bekerja (E0/G0) dan membandingkan hasil akhir dengannya.
