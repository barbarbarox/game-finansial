# STYLE BIBLE — Tambahan v6 (perspektif furnitur, set meja-kursi, Budi, panduan visual)

> Melengkapi STYLE-BIBLE.md, -INTERIOR, -V4. STYLE BLOCK dan NEGATIVE BLOCK yang sama tetap dipakai.

## 1. Kontrak perspektif
Semua furnitur: kamera menunduk ±20–25° dari depan; **front** (muka sejajar bidang gambar, simetris kiri-kanan), **back** (dilihat dari belakang), atau **left/right** (tampak samping murni). **Tidak ada** miring/diagonal/isometrik. Prompt memuat klausa "strict front elevation … NOT diagonal, NOT isometric, NOT rotated" atau "seen from directly behind".

## 2. Set meja + kursi (satu sprite komposit)
- **Meja siswa:** meja kayu frontal + kursi kayu di depan kamera dilihat dari belakang (sandaran menghadap kamera) menimpa bagian bawah meja. Dua variasi nada kayu.
- **Set kantin:** meja panjang frontal + bangku dekat dilihat dari belakang + bangku jauh terlihat di balik meja; gelas generik tanpa label.
- **Set baca:** meja frontal + dua kursi dilihat dari belakang; buku abstrak di atas meja.
- **Papan tulis:** papan hijau berbingkai kayu, frontal, kosong total. **Meja guru:** frontal, kertas abstrak.

## 3. Kamar mandi dan dapur (identitas jelas)
Bak mandi = bak ubin persegi berisi air + gayung di tepi; toilet duduk keramik dengan tangki; wastafel + faucet + cermin persegi kosong; rak handuk berdiri; ember plastik. Rak piring dinding berisi piring/mangkuk hijau-krem; jendela dapur berbingkai kayu bergorden hijau. Setiap objek harus langsung dikenali sesuai namanya.

## 4. Budi (sprite dunia)
Remaja SMA ±16 tahun, rambut hitam cepak dengan jambul kecil, seragam putih lengan digulung, bawahan abu-abu `#9AA0AA`, tas selempang mustard `#D9A441`, sepatu putih, postur santai ramah, sedikit lebih tinggi dari protagonis. Gaya piksel identik dengan sprite pemain (tepi tajam, tanpa alfa parsial, outline 1 px, shading 2–3 nada). Bukan kartun halus. Konsisten dengan `portrait_teman_l`.

## 5. Panah pemandu dan petunjuk tutorial
Panah piksel mustard `#D9A441` beroutline navy, melayang 1–2 px; ikon tombol (E/Klik) dalam bingkai krem bersudut piksel; bingkai sorotan HUD berdenyut mustard. Tanpa glow halus; hanya token palet.
