# game-finansial

Prototype Game Edukasi Literasi Keuangan (Fase 1: Kehidupan SMA) untuk kompetisi Pilmapres.

## Fitur
- Simulasi kehidupan SMA (uang saku bulanan, belanja, bensin, tabungan, anggaran)
- Ledger append-only double-entry
- Dunia top-down 3/4 RPG (Phaser 3)
- Panel interaktif DOM overlay
- Offline-first tanpa backend / login
